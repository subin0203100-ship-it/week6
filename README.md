# 하중 분석 GUI

Tkinter와 Matplotlib로 만든 CSV 하중 분석 프로그램입니다. CSV에서 시간과 하중을 읽고, 선택한 단면의 면적으로 응력을 계산하여 최대 응력과 발생 시간을 표시합니다.

## 실행 방법

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
cd "C:\Users\subin\OneDrive\Desktop\코딩과응용"
python -m pip install matplotlib
python .\load_analyzer_gui.py
```

VS Code에서는 Python 인터프리터를 선택하고 `load_analyzer_gui.py`를 연 다음 **Run Python File**을 실행해도 됩니다. Python에 Tkinter가 포함되어 있어야 하며, 그래프를 위해 Matplotlib가 필요합니다.

## 사용 순서

1. **CSV 찾아보기**를 눌러 CSV 파일을 선택합니다.
2. 유효 데이터 수와 제외 데이터 수를 확인합니다.
3. 단면 종류를 선택하고 필요한 치수를 입력합니다.
4. 단면적을 확인한 뒤 **분석**을 누릅니다.
5. 최대 응력과 해당 시간을 확인하고 하단 시간-응력 그래프를 확인합니다.

## CSV 형식

필수 열 이름은 다음 두 가지이며, 이름은 정확히 일치해야 합니다.

```csv
time_s,force_N
0,0
1,100
2,250
```

- `time_s`: 시간, 단위 `s`
- `force_N`: 하중, 단위 `N`
- 숫자가 아니거나 빈 값인 행, 무한대 또는 NaN 값이 있는 행은 제외됩니다.
- 화면에는 유효 데이터 수와 제외 데이터 수가 표시됩니다.

## 단면별 치수와 계산식

모든 치수의 단위는 `mm`이며, 단면적의 단위는 `mm²`입니다. 응력은 `N/mm²`와 같은 값인 `MPa`로 표시합니다.

| 단면 종류 | 필요한 치수 | 단면적 계산식 | 유효 조건 |
| --- | --- | --- | --- |
| 사각형 | 폭 `b`, 높이 `h` | `A = b × h` | `b > 0`, `h > 0` |
| 원형봉 | 지름 `d` | `A = π × d² / 4` | `d > 0` |
| 원형관 | 외경 `D`, 두께 `t` | `A = π × [D² - (D - 2t)²] / 4` | `D > 0`, `t > 0`, `2t < D` |
| 사각형관 | 외측 폭 `B`, 외측 높이 `H`, 두께 `t` | `A = B × H - (B - 2t) × (H - 2t)` | 모든 치수 `> 0`, `2t < B`, `2t < H` |
| H형강 | 전체 높이 `H`, 플랜지 폭 `B`, 웹 두께 `tw`, 플랜지 두께 `tf` | `A = 2 × B × tf + (H - 2tf) × tw` | 모든 치수 `> 0`, `2tf < H`, `tw < B` |

응력은 각 CSV 행에 대해 다음과 같이 계산합니다.

```text
stress = force_N / A
```

## 이상화 단면 가정

- 사각형관은 모서리 곡률과 용접부를 무시한 날카로운 직사각형 중공 단면으로 계산합니다.
- H형강은 필렛, 모서리 곡률, 실제 압연 형상을 무시한 단순 조합 단면으로 계산합니다.
- 하중은 단면 전체에 균일하게 작용한다고 가정합니다.
- 응력은 축방향 하중을 단면적으로 나눈 평균 응력입니다.

## 오류 처리 규칙

- CSV 파일을 읽을 수 없으면 오류 메시지를 표시하고 분석을 중단합니다.
- 필수 열이 없으면 누락된 열과 필요한 열 이름 `time_s`, `force_N`을 안내합니다.
- 유효한 데이터가 하나도 없으면 `유효한 데이터가 없습니다.`를 안내하고 분석을 중단합니다.
- 숫자가 아닌 입력, 빈칸, 0, 음수는 치수 오류로 안내합니다.
- 원형관의 `2t >= D`, 사각형관의 `2t >= B` 또는 `2t >= H`, H형강의 `2tf >= H` 또는 `tw >= B`는 계산하지 않습니다.
- CSV, 단면 종류, 치수가 변경되면 이전 응력 결과와 그래프는 무효화되고 `조건변경됨: 다시분석필요`가 표시됩니다.
- 오류가 발생해도 이전 결과를 현재 결과로 남기지 않습니다. 올바른 값을 입력하고 **분석**을 다시 누르면 결과와 그래프가 갱신됩니다.
- 파일 선택 창에서 **취소**하면 기존 화면 상태를 유지합니다.
